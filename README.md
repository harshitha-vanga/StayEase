
# 🏨 StayEase – Hotel Booking Website

StayEase is a Django-based hotel booking web application that allows users to explore hotels, check room availability, book rooms, and manage their reservations.

## 🚀 Features

- User Registration and Login
- Browse and Search Hotels
- Hotel Details and Pricing
- Room Availability Checking
- Online Booking Workflow
- Demo UPI and Card Payment Interface
- Booking Confirmation
- My Bookings Dashboard
- Cancel Reservations
- Booking Receipt and PDF Printing
- Admin Dashboard
- Hotel and Booking Management
- Responsive User Interface

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/harshitha-vanga/StayEase.git
```

### 2. Open the project folder

```bash
cd StayEase
```

### 3. Create a virtual environment

```bash
python3 -m venv venv
```

### 4. Activate the environment

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply migrations

```bash
python3 manage.py migrate
```

### 7. Run the development server

```bash
python3 manage.py runserver
```

Open your browser:

http://127.0.0.1:8000/

## 💳 Payment Information
